# Continue-my-journey-
A collection of C++ problem-solving exercises and structural programming fundamentals


Problem #1: Cinema Reservation System 🎬 (The Learning Journey)
​أهلاً بيكم! ده أول مشروع ليا في مادة الـ Structured Programming. البرنامج فكرته بسيطة: "نظام حجز لسينما فيها 3 قاعات".
​في المشروع ده، أنا محبيتش أرفع الكود النهائي وبس، أنا حبيت أشارككم إزاي الكود بتاعي اتطور من مجرد "كود شغال" لكود "مكتوب صح"، وإيه الأخطاء اللي وقعت فيها عشان الكل يستفيد.
​🚀 إيه هو البرنامج؟ (The Project)
​نظام بيخليك تدخل بيانات 3 قاعات (رقم القاعة واسم الفيلم)، وبعدين تقدر تحجز تذاكر. البرنامج بيتأكد لو فيه مكان فاضي (السعة 50 كرسي) وبيطلعلك رقم القاعة والباقي كام كرسي.
​🛠️ رحلة تطوير الكود (The Evolution)
​❌ المرحلة الأولى: الكود المبتدئ (Static Logic)
​في البداية، كنت كاتب الكود باستخدام if و else if يدوية لكل قاعة.
​المشكلة: الكود كان طويل جداً وغير مرن. لو القاعات بقت 10، كنت هضطر أكتب 10 شروط يدوية!
​الخطأ التاني: مكنتش بشيك لو القاعة مليانة ولا لأ، كان أي حد يحجز أي عدد تذاكر والبرنامج يوافق عادي.
​⚠️ المرحلة الثانية: مشكلة الـ Loop والـ Else
​لما قررت أستخدم الـ for loop عشان أخلي الكود أذكى، وقعت في غلطة مشهورة جداً: حطيت رسالة الـ "Error" جوه اللوب.
​النتيجة: البرنامج كان بيطبع "Reservation cannot be made" مع كل قاعة مش هي المطلوبة، حتى لو الحجز نجح في القاعة اللي بعدها! (تخيل العميل يشوف رسالة رفض 3 مرات وبعدين يقوله تم الحجز!).
​✅ المرحلة الثالثة: الكود الاحترافي (Clean & Scalable)
​ده الكود النهائي اللي رفعته، والتحسينات اللي عملتها هي:
​استخدام الـ Flag: عرفت متغير bool found = false عشان البرنامج يدور في صمت.
​البحث الذكي: استخدمت for loop واحدة بتلف على أي عدد من القاعات.
​شرط السعة: ضفت شرط (h[i].seats + tickets <= capacity) عشان أتأكد إن فيه مكان فعلاً قبل ما أوافق.
​الترتيب الصح: طلعت رسالة الرفض بره اللوب خالص، عشان متظهرش غير لو البرنامج فعلاً ملقاش الفيلم في كل القاعات.
​💡 اتعلمت إيه؟ (Lessons Learned)
​Don't Repeat Yourself (DRY): لو لقيت نفسك بتكرر if كتير، استخدم loop.
​Check logic before output: مش أي حاجة تطلع للمستخدم فوراً، اتأكد من النتيجة النهائية الأول.
​Structs are powerful: الـ Struct خلى تنظيم بيانات القاعة أسهل بكتير من استخدام متغيرات منفصلة
